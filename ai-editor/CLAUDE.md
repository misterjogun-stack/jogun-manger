# AI 영상 편집 작업 규칙

이 폴더에서 영상 편집을 맡으면 아래를 지킨다. 사용법은 README.md.

1. 편집은 `autoedit.py`로 한다. 직접 ffmpeg 명령을 새로 짜기 전에 `autoedit.py --help`를 먼저 본다.
2. 받아쓰기는 Whisper `large-v3-turbo`를 `--compute-type int8`로 쓴다. 일반 Whisper large를 그대로 돌리지 않는다(사양이 낮은 컴퓨터에서 멈춘다).
3. 재촬영은 "1초 이상 멈춤 뒤 같은 말이 다시 나옴"으로 판단한다. 반복된 말은 **앞부분을 지우고 뒷부분을 살린다.** 작업 뒤 `report.json`의 `retakes`를 사용자에게 보여 주고, 멀쩡한 문장이 지워졌으면 `--ratio`를 올려 다시 돌린다.
4. 자막은 `netflix_ko.json`의 값을 따른다. 작업 시작 시 넷플릭스 한국어 자막 지침 원문(https://backlothelp.netflix.com/hc/en-us/articles/216001127)을 읽고 `verified: false` 항목을 대조해 고친다. 원문을 읽지 못하면 못 읽었다고 말하고, 기억으로 지침을 지어내지 않는다.
5. 효과음은 말소리를 가리지 않게 작고 짧게 쓴다(기본 -16dB). 만든 소리는 직접 들어 보고 평가한다. 점수만 믿지 않는다.
6. 모션그래픽은 HyperFrames를 쓴다. 리모션은 쓰지 않는다. 설치 전 저장소 LICENSE를 확인한다.
7. 원본 영상은 덮어쓰지 않는다. 결과는 `out/`에 쓴다.
8. 끝나면 줄어든 길이, 재촬영 삭제 목록, 자막 경고 수를 짧게 보고한다. 하지 못했거나 확인하지 못한 단계는 그대로 밝힌다.
