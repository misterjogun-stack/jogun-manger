1분 시작

영상 편집기 · 컴퓨터와 안드로이드 크롬에서 가장 잘 돼요

  1. 편집기를 열고 왼쪽 파일 불러오기를 눌러 영상을 고르세요. 여러 개를 한꺼번에 골라도 돼요.
  2. 영상을 처음 불러오면 자동 편집 창이 저절로 떠요.
  3. 필요한 항목만 켜 두고 자동 편집 시작을 누르세요.
  4. 끝나면 결과 보기를 눌러 재생해 보고, 마음에 들면 오른쪽 위 내보내기를 누르세요.
결과가 마음에 안 들면 Ctrl+Z 한 번으로 자동 편집 전으로 돌아가요. 폰에서는 위쪽 되돌리기 버튼을 누르세요.

자동 편집 세 가지

위쪽 보라색 자동 편집 버튼에서 고를 수 있어요

① 원클릭 자동 편집

불러온 영상을 파일 이름 순서로 이어 붙이고, 켜 둔 작업을 한 번에 처리해요.

항목하는 일
말 없는 구간 컷멈칫하거나 숨 고르는 구간을 잘라 템포를 빠르게 해요. 컷 강도를 높이면 더 많이 잘라요. 자를 최소 무음은 이 길이보다 긴 침묵만 자르는 기준이에요. 말 앞뒤 여유는 말이 잘리지 않게 남기는 시간이에요.
AI 자동 자막말소리를 받아 적어 자막으로 넣어요. 언어와 자막 스타일을 고를 수 있어요.
배경음악미리 불러온 음악 파일을 깔아요. 영상보다 짧으면 반복하고, 말할 때는 소리를 자동으로 줄여요.
인트로 타이틀맨 앞 2.5초에 제목 글자를 넣어요. 비워 두면 파일 이름을 써요.
페이드 · 챕터클립 사이를 부드럽게 넘기고, 파일마다 유튜브 챕터 마커를 찍어요.
AI 자막은 처음 한 번 AI 모델(약 80~250MB)을 내려받아요. 인터넷이 필요하고, 컴퓨터가 느리면 영상 길이만큼 걸릴 수 있어요. 이 웹 페이지 버전에서는 모델 내려받기가 막혀 있을 수 있어요. 안 되면 나머지 편집은 그대로 끝나고, 자막만 컴퓨터에 저장한 HTML 파일 버전에서 만들 수 있어요.

② 음악 박자 몽타주

  1. 음악 파일과 사진·영상을 먼저 불러오세요.
  2. 음악 박자 몽타주 탭에서 음악, 컷 빠르기, 길이를 고르세요.
  3. 쓸 사진과 영상에 체크하고 몽타주 만들기를 누르세요.

음악의 템포를 찾아서 박자마다 장면을 바꿔요. 여행·브이로그 인트로에 잘 어울려요. 지금 타임라인은 새 몽타주로 바뀌지만 되돌리기로 복구돼요.

③ 쇼츠 자동 만들기

  1. 먼저 영상을 타임라인에 올리거나 원클릭 자동 편집을 하세요.
  2. 쇼츠 자동 만들기 탭에서 길이(15~60초)를 고르세요. 위쪽에 넣을 제목은 선택이에요.
  3. 쇼츠 만들기를 누르면 말이 가장 많이 몰린 구간을 골라 세로 화면으로 바꿔요.

직접 고치기

자동으로 된 결과를 손으로 다듬을 때

  • 자르기: 자를 곳에 재생 막대를 놓고 자르기 버튼이나 S를 눌러요.
  • 순서 바꾸기: 영상 줄의 클립을 끌어서 옮겨요.
  • 앞뒤 줄이기: 클립 양 끝의 흰 손잡이를 끌어요.
  • 자막 고치기: 텍스트 줄의 자막을 누르면 오른쪽에서 내용, 글꼴, 색, 테두리, 등장 효과를 바꿀 수 있어요. 미리보기 화면의 자막을 끌어서 위치도 옮겨요.
  • 필터와 속도: 영상 클립을 누르면 오른쪽에서 필터, 밝기, 속도(0.25~4배), 볼륨을 조절해요.
  • 화면 비율: 아무것도 선택하지 않은 상태에서 오른쪽 프로젝트 설정의 화면 비율을 바꿔요. 쇼츠는 9:16이에요.
  • 배경음악 볼륨: 오디오 줄의 음악을 누르고 볼륨을 20~40%로 두면 목소리를 가리지 않아요.

내보내기와 유튜브 올리기

  1. 오른쪽 위 내보내기를 누르고 해상도를 고르세요. 720p가 빠르고, 1080p가 더 선명해요.
  2. 내보내기 시작을 누르면 화면을 실시간으로 녹화해요. 영상 길이만큼 걸리니 끝날 때까지 탭을 열어 두세요.
  3. 끝나면 저장하기를 눌러 파일로 저장하세요.
  4. 유튜브 스튜디오에서 영상을 올리고, 아래 항목도 챙겨 보세요.
  • 챕터: 아무것도 선택하지 않은 상태에서 오른쪽 유튜브 챕터의 설명란용으로 복사를 눌러 설명란에 붙여 넣어요. 0:00으로 시작하고 3개 이상이어야 챕터로 인식돼요.
  • 자막 파일: SRT 내보내기로 받은 파일은 이름 끝의 .txt를 지우고 유튜브 자막으로 올려요.
  • 썸네일: 원하는 장면에서 멈추고 위쪽 썸네일 버튼을 누르면 그 장면이 이미지로 저장돼요.
배경음악은 유튜브에 써도 되는 곡이어야 해요. 유튜브 스튜디오의 오디오 보관함 음악은 무료로 쓸 수 있어요. 아이폰 사파리에서는 내보내기가 안 될 수 있어요.

블로그 자동 글쓰기

제목만 넣으면 글이 나와요

  1. 먼저 내 정보 탭에서 블로그 이름, 글쓴이 소개, 지역(시·도, 구, 동, 상세 주소), 지도 링크, 전화, 영업시간을 적고 내 정보 저장을 눌러요. 한 번만 하면 돼요.
  2. 글 제목에 주제나 제목을 적고, 핵심 키워드에는 사람들이 검색할 말 한 가지를 적어요. 막막하면 제목 추천과 키워드 확장을 눌러 보세요.
  3. 올릴 곳(네이버, 티스토리, 브런치)과 길이, 말투를 골라요. 올릴 곳에 따라 문단 길이와 소제목 모양이 달라져요.
  4. 직접 겪은 일이나 꼭 넣을 사실이 있으면 꼭 넣고 싶은 내용에 적어요. 적은 내용만 사실로 쓰고, 없는 숫자나 후기는 지어내지 않아요.
  5. 글 써 주세요를 누르면 길게는 1분쯤 뒤에 소제목, 사진 자리, 요약, 해시태그까지 갖춘 글이 나와요.
  6. 고치고 싶으면 아래 칸에 "더 짧게", "첫 문단을 더 재밌게"처럼 적고 이대로 고쳐 쓰기를 눌러요.
  7. 글 복사를 눌러 블로그 글쓰기 창에 붙여 넣어요. 티스토리 마크다운 모드는 마크다운 복사를 써요.

검색·AI 노출을 위해 자동으로 하는 일

  • 검색(SEO): 핵심 키워드를 제목 앞쪽, 첫 문단, 소제목에 넣고 본문에서는 과하지 않게 반복해요. 메타 설명, 슬러그, 태그도 만들어 줘요.
  • AI 답변(GEO): 글 맨 위에 질문에 대한 직접 답인 한 줄 요약을 두고, 소제목마다 답부터 써요. 표, 목록, 자주 묻는 질문(FAQ)을 넣어 AI가 가져가기 쉽게 해요.
  • 지역·지도: 내 정보의 주소, 전화, 영업시간, 지도 링크를 글 끝 위치·이용 안내에 같은 표기로 넣고, 지역 키워드를 본문에 자연스럽게 섞어요.
  • 신뢰: 글쓴이, 작성일, 소개를 넣어요. 직접 겪은 일에 적은 내용만 경험으로 쓰고 없는 후기는 지어내지 않아요.
  • 점수 점검: 글이 끝나면 제목 길이, 키워드 위치, 분량, FAQ 같은 항목을 점수로 보여 주고, 부족한 점 자동 보완을 누르면 고쳐서 다시 써 줘요.
  • 구조화 데이터: 티스토리 HTML 모드나 워드프레스에는 구조화 데이터(JSON-LD) 복사로 만든 코드를 붙여 넣어요. 네이버 블로그에는 넣을 수 없어요.
어떤 도구도 검색 순위를 보장할 수는 없어요. 이 도구는 검색엔진과 AI가 공통으로 중요하게 보는 기본기를 빠짐없이 적용해 줘요. 키워드 검색량은 알 수 없으니 네이버 검색광고 키워드도구로 확인하세요. 발행 후 체크리스트는 글 아래에 있어요.
글 속의 [사진: …] 자리에는 직접 찍은 사진을 넣고, 노란 [확인 필요: …] 표시는 사실을 확인해서 고친 뒤 올리세요. 가격, 영업시간, 주소는 꼭 직접 확인해야 해요.
글은 Claude가 써서 사용자의 Claude 사용량을 써요. 처음 쓸 때 허용 창이 뜨면 허용을 눌러야 해요. 최근에 쓴 글 8개는 이 브라우저에만 저장돼요.

막힐 때

영상이 안 열려요

브라우저가 읽지 못하는 형식일 수 있어요. 안드로이드나 아이폰 기본 카메라로 찍은 mp4와 mov는 대부분 열려요. 안 열리는 파일은 다른 형식(mp4)으로 바꿔서 불러오세요.

자막이 안 만들어져요

AI 모델 내려받기에는 인터넷이 필요해요. 연결을 확인한 뒤 자동 편집을 다시 하세요. 웹 페이지 버전에서는 막혀 있을 수 있으니, 컴퓨터에 저장한 HTML 파일을 크롬이나 엣지로 열어 보세요.

컷이 너무 많이 / 적게 잘려요

자동 편집 창에서 컷 강도와 자를 최소 무음을 바꿔서 다시 하세요. 배경에 소음이 큰 영상은 강도를 높이고, 말이 잘리면 말 앞뒤 여유를 늘리세요.

작업이 사라졌어요

작업 내용과 불러온 파일은 이 브라우저에 자동 저장돼요. 시크릿 모드나 사이트 데이터 삭제를 하면 사라지니, 중요한 영상은 내보내서 따로 보관하세요.
